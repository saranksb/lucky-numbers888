🔮 เลขมงคล (สนุกๆ)

เครื่องมือทดลองใช้ทฤษฎี Gambler's Fallacy เพื่อความบันเทิง — เก็บเลขที่เคยซื้อ ดูสถิติงวดที่ผ่านมา และดูตัวชี้วัด "เลขค้างงวด"

⚠️ เพื่อความสนุกเท่านั้น แต่ละงวดของสลากกินแบ่งรัฐบาลเป็นอิสระจากกันทางสถิติ 100% "เลขที่ไม่ออกมานาน" ไม่ได้มีโอกาสออกมากกว่าเลขอื่นเลยแม้แต่น้อย — ตัวชี้วัดในหน้านี้คำนวณจากความเชื่อผิดๆ ตามทฤษฎี Gambler's Fallacy ล้วนๆ ไม่ใช่การพยากรณ์ที่แม่นยำ ห้ามใช้ตัดสินใจทางการเงินจริงจัง

+ ลองดึงข้อมูลอัตโนมัติจาก API (อาจใช้ไม่ได้ ขึ้นกับว่ามี API ที่ยังทำงานอยู่ไหม)

🔮 พยากรณ์รางวัลที่ 1 (โมเดลความถี่รายหลัก)

คำนวณ % จาก "ส่วนแบ่งความถี่ในอดีต" ของแต่ละหลัก ไม่ใช่ความน่าจะเป็นจริงของงวดถัดไป — แต่ละงวดสุ่มเป็นอิสระ 100% ทำไว้เป็นแบบฝึกหัดสถิติ/โปรเจกต์วิจัยเท่านั้น

🧪 ทดสอบทางสถิติ

ใช้ชุดข้อมูลเดียวกับตัวเลือก pool ในส่วนพยากรณ์ด้านบน — ถ้าติ๊กเปลี่ยนตรงนั้น ผลตรงนี้จะคำนวณใหม่ตามด้วย

Chi-square goodness-of-fit (เทียบกับสมมติฐานว่าแต่ละหลักสุ่มสม่ำเสมอ 10% ต่อตัวเลข)

ตำแหน่งNχ²p-valueผล

Backtest (ย้อนทดสอบโมเดลกับงวดจริงที่ผ่านมา)

ถ้าโมเดลทายได้ดีกว่าสุ่มจริง อัตราถูกระดับหลักควรสูงกว่า 30% อย่างมีนัยสำคัญ และควรเจอ "ถูกเป๊ะทั้ง 6 หลัก" บ่อยกว่า ~0.001% ต่อครั้งมาก — ถ้าตัวเลขใกล้ค่าคาดหวังโดยบังเอิญ แปลว่าโมเดลนี้ไม่มีความสามารถพยากรณ์จริง ตามที่ควรจะเป็น เพราะแต่ละงวดสุ่มเป็นอิสระ 100%
