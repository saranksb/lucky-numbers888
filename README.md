# เลขมงคล (Gambler's Fallacy) 🔮

เครื่องมือสนุกๆ สำหรับคนที่ชอบเล่นสลากกินแบ่งรัฐบาลไทย — เก็บเลขที่เคยซื้อ ดูสถิติผลรางวัลย้อนหลัง
และดูตัวชี้วัด "เลขค้างงวด" ที่คำนวณจากทฤษฎี **Gambler's Fallacy**

> ⚠️ **เพื่อความบันเทิงเท่านั้น** แต่ละงวดของสลากกินแบ่งรัฐบาลเป็นอิสระจากกันทางสถิติ 100%
> "เลขที่ไม่ออกมานาน" ไม่ได้มีโอกาสออกมากกว่าเลขอื่นแม้แต่น้อย ตัวชี้วัดในเว็บนี้อิงจากความเชื่อผิดๆ
> ล้วนๆ ไม่ใช่การพยากรณ์ที่แม่นยำ ห้ามใช้ตัดสินใจทางการเงินจริงจัง

## ใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้อง build/ติดตั้งอะไร) หรือจะโฮสต์ผ่าน
[GitHub Pages](https://pages.github.com/) ก็ได้ — ไปที่ Settings → Pages ของ repo นี้
แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`

## ฟีเจอร์

- **เลขที่เคยซื้อ** — บันทึกงวด/ประเภท/เลขที่ซื้อ เก็บไว้ในเบราว์เซอร์ (localStorage) พร้อม
  export/import เป็นไฟล์ JSON และเช็คผลถูก/ไม่ถูกให้อัตโนมัติเมื่อมีผลรางวัลของงวดนั้นแล้ว
- **สถิติผลรางวัลย้อนหลัง** — ดึงจาก [lottery.api.rayriffy.com](https://github.com/rayriffy/lotto-thai-result)
  ซึ่งเป็น API โอเพนซอร์สฟรีที่รวบรวมผลสลากกินแบ่งรัฐบาลไทย (ไม่ต้องสมัคร ไม่ต้องมี API key) —
  ตั้งค่า base URL เองได้ในหน้าเว็บเผื่อ API นี้ย้ายที่/ล่ม และมีช่องกรอกผลย้อนหลังด้วยตนเองสำรองไว้ด้วย
- **ตัวชี้วัด Gambler's Fallacy** — คำนวณ "เลขค้างงวด" (ไม่ออกมานานกี่งวดแล้ว) แยกตาม 4 ประเภท:
  รางวัลที่ 1, 3 ตัวหน้า, 3 ตัวท้าย, เลขท้าย 2 ตัว พร้อมปุ่มสุ่มเลขแนะนำจากทฤษฎีนี้

## ทำไมไม่ดึงข้อมูลจาก glo.or.th โดยตรง

เว็บ [glo.or.th](https://www.glo.or.th) ไม่มี API สาธารณะให้เว็บอื่นเรียกข้ามโดเมนได้ (หน้าเว็บ render
ด้วย JavaScript และไม่เปิด CORS) จึงใช้ API ของ `lottery.api.rayriffy.com` ซึ่งเป็นชุมชนโอเพนซอร์ส
ที่รวบรวมผลสลากกินแบ่งรัฐบาลไว้แทน

## โครงสร้างไฟล์

```
js/lotto.js    ตรรกะทั้งหมด: ดึง API, คำนวณสถิติ, บันทึก localStorage
```
